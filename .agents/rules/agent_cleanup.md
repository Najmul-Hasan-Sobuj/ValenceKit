# Agent Cleanup Rule

Whenever you (the agent) generate an unwanted or temporary file during your workflow (like a test file, a `.py` script for calculating something, temporary `.html` files, or scratchpads in the workspace directory), you MUST remove those files after your work is done and before finishing your task.

Keep the user's workspace clean and do not leave artifacts of your problem-solving process lying around unless explicitly asked to save them.
